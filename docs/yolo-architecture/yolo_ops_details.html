YOLOv8n: mathematical operations per block

Date: 15 October 2026, Version: 1.0, Last edit time: 22:19 AEDT, 15 October · pairs with yolo_architecture.html, version 1.0

Each section lists the operations of one block of the architecture diagram, in execution order, with the YOLOv8n channel counts at a 640×640 input. Notation: x[c, i, j] is the value at channel c, row i, column j of a feature map; x is a block's input and y its output. The operations are defined in the table at the end. Multiplication counts are computed from the layer shapes; exponentials, divisions and comparisons are not counted as multiplications.

Definitions of operations

x is the input, y the output. Cin, Cout: input and output channels. H, W: rows and columns. Indices start at 0.

OperationDefinitionNotes
Convolution + bias
k×k, stride s, padding p		y[o, i, j] = b[o] + Σc=0..Cin−1 Σu=0..k−1 Σv=0..k−1 w[o, c, u, v] · x[c, s·i + u − p, s·j + v − p]
Hout = ⌊(H + 2p − k) / s⌋ + 1		x outside the map counts as 0. Each output value uses Cin·k·k multiplications. 3×3 uses p = 1; 1×1 uses p = 0. Stride 2 halves H and W.
Batch normalisation (folded into the convolution)w′[o, …] = γ[o] / √(σ²[o] + ε) · w[o, …]
b′[o] = β[o] − γ[o] · μ[o] / √(σ²[o] + ε)		Done once, before inference. γ, β learned; μ, σ² training statistics. Afterwards only convolution + bias remains.
Sigmoidσ(z) = 1 / (1 + e−z)Output between 0 and 1. Used in SiLU and for the class scores.
SiLUSiLU(z) = z · σ(z) = z / (1 + e−z)Applied to every value separately.
Residual addy[c, i, j] = x[c, i, j] + f(x)[c, i, j]f is the bottleneck's two convolutions. x and f(x) have equal shapes.
BottleneckBottleneck(x) = x + SiLU(Conv3×3(SiLU(Conv3×3(x))))
Bottleneckno-res(x) = SiLU(Conv3×3(SiLU(Conv3×3(x))))		Backbone C2f blocks use the first form, neck C2f blocks the second.
C2f, n bottlenecksa | b = Split(SiLU(Conv1×1(x)))
m1 = Bottleneck(b), mk = Bottleneck(mk−1)
y = SiLU(Conv1×1(Concat(a, b, m1, …, mn)))		Every intermediate mk is kept and concatenated.
Channel splita = x[0 .. C/2 − 1, i, j],   b = x[C/2 .. C − 1, i, j]Selects channel ranges; no arithmetic.
Channel concatenationy[c, i, j] = x1[c, i, j] for c < C1;
y[c, i, j] = x2[c − C1, i, j] for C1 ≤ c < C1 + C2; and so on		Stacks maps of equal H and W along channels; no arithmetic.
Max-pool k×k, stride 1, padding py[c, i, j] = maxu, v = 0..k−1 x[c, i + u − p, j + v − p]x outside the map counts as −∞. SPPF uses k = 5, p = 2, so H and W are unchanged.
