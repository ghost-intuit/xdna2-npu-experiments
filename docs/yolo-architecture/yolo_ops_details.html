YOLOv8n: operations, work and data per block

Date: 15 October 2026, Version: 1.7, Last edit time: 22:30 AEDT, 16 October · pairs with yolo_architecture.html, version 1.7

An index of the blocks in the architecture diagram, for YOLOv8n at a 640×640 input. The chart compares the blocks; each block card opens a page with its structure, the memory it holds step by step, and every operation with its shapes and counts. The operations are defined in the table below, with sources at the end. All counts are computed from the YOLOv8n layer shapes [1].

Bytes shown for: Applies to every byte figure on this page and is remembered across pages. MB = 1,000,000 bytes. Weights are counted after batch normalisation is folded in: one weight per kernel entry plus one bias per output channel.*Note: for the bf16 and bfp16 definitions, see AMD Quark documentation: BF16 (bfloat16) and BFP16 (block floating point).

Work and data per block

Figure 2 – Work and data per block, YOLOv8n

Totals: 4,371,456,000 multiplications, that is 8.74 billion operations counting 2 per multiply-add; Ultralytics publishes 8.7 GFLOPs [2]. Weights: 3,151,888 values; before batch normalisation is folded in, as trained, the model has 3,157,200 parameters, matching the published 3.2 million [2].

Definitions of operations

x is the input, y the output. Cin, Cout: input and output channels. H, W: rows and columns. Indices start at 0.

OperationDefinitionNotes
Convolution + bias
k×k, stride s, padding p		y[o, i, j] = b[o] + Σc=0..Cin−1 Σu=0..k−1 Σv=0..k−1 w[o, c, u, v] · x[c, s·i + u − p, s·j + v − p]
Hout = ⌊(H + 2p − k) / s⌋ + 1		x outside the map counts as 0. Each output value uses Cin·k·k multiplications. 3×3 uses p = 1; 1×1 uses p = 0. Stride 2 halves H and W.
Batch normalisation (folded into the convolution) [3]w′[o, …] = γ[o] / √(σ²[o] + ε) · w[o, …]
b′[o] = β[o] − γ[o] · μ[o] / √(σ²[o] + ε)		Done once, before inference. γ, β learned; μ, σ² training statistics. Afterwards only convolution + bias remains.
Sigmoidσ(z) = 1 / (1 + e−z)Output between 0 and 1. Used in SiLU and for the class scores.
SiLU [4][5]SiLU(z) = z · σ(z) = z / (1 + e−z)Applied to every value separately.
Residual addy[c, i, j] = x[c, i, j] + f(x)[c, i, j]f is the bottleneck's two convolutions. x and f(x) have equal shapes.
BottleneckBottleneck(x) = x + SiLU(Conv3×3(SiLU(Conv3×3(x))))
Bottleneckno-res(x) = SiLU(Conv3×3(SiLU(Conv3×3(x))))		Backbone C2f blocks use the first form, neck C2f blocks the second.
C2f, n bottlenecksa | b = Split(SiLU(Conv1×1(x)))
m1 = Bottleneck(b), mk = Bottleneck(mk−1)
y = SiLU(Conv1×1(Concat(a, b, m1, …, mn)))		Every intermediate mk is kept and concatenated.
Channel splita = x[0 .. C/2 − 1, i, j],   b = x[C/2 .. C − 1, i, j]Selects channel ranges; no arithmetic.
Channel concatenationy[c, i, j] = x1[c, i, j] for c < C1;
y[c, i, j] = x2[c − C1, i, j] for C1 ≤ c < C1 + C2; and so on		Stacks maps of equal H and W along channels; no arithmetic.
Max-pool k×k, stride 1, padding py[c, i, j] = maxu, v = 0..k−1 x[c, i + u − p, j + v − p]x outside the map counts as −∞. SPPF uses k = 5, p = 2, so H and W are unchanged.
Nearest upsample ×2y[c, i, j] = x[c, ⌊i / 2⌋, ⌊j / 2⌋]Each value is copied to a 2×2 area; no arithmetic.
Bilinear resize, gain g [7]r = (i + 0.5) / g − 0.5,   q = (j + 0.5) / g − 0.5,   r0 = ⌊r⌋, q0 = ⌊q⌋, α = r − r0, β = q − q0
y[c, i, j] = (1−α)(1−β)·x[c, r0, q0] + (1−α)β·x[c, r0, q0+1] + α(1−β)·x[c, r0+1, q0] + αβ·x[c, r0+1, q0+1]		A weighted average of the 4 nearest source values. g = min(640 / H, 640 / W).
Padding and scalingy[c, i, j] = 114 outside the resized image; then y / 255Padding fills the 640×640 canvas; scaling maps 0–255 to 0–1.
Channel reordery[c, i, j] = x[2 − c, i, j]BGR to RGB; no arithmetic.
Softmax over 16 bins [6]pk = ezk / Σm=0..15 ezm,   k = 0..15For each box edge at each position. The pk are positive and sum to 1.
Expected distance (DFL) [6]d = Σk=0..15 k · pkDistance from the cell centre to one box edge, in grid cells.
Box from distancescx = j + 0.5, cy = i + 0.5
x1 = (cx − dl)·s, y1 = (cy − dt)·s, x2 = (cx + dr)·s, y2 = (cy + db)·s		s is the stride of the head: 8, 16 or 32. Gives the box in 640×640 coordinates. Decode returns it as centre x, centre y, width and height: ((x1 + x2)/2, (y1 + y2)/2, x2 − x1, y2 − y1); NMS converts it back to corners x1, y1, x2, y2. The box is the same.
Confidence thresholdscore = maxc σ(zc); keep if score > τconfτconf, for example 0.25.
IoUw = max(0, min(x2A, x2B) − max(x1A, x1B)), h likewise for y
IoU(A, B) = w·h / (area(A) + area(B) − w·h)		Overlap of two boxes, from 0 (none) to 1 (identical).
Non-maximum suppressionSort boxes by score, highest first. Repeat: keep the first box; remove every remaining box of the same class with IoU > τIoU against itτIoU, for example 0.7. Removes duplicate detections of one object.
Undo the letterboxx = (x′ − padx) / g,   y = (y′ − pady) / gMaps box corners back to the original image.
