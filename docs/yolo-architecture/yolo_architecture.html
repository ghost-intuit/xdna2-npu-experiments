How to read it: the backbone runs top to bottom and finishes first. Its outputs B3, B4 and S5 are kept and picked up later by the neck. The neck then runs in the numbered order 1 → 4: up the FPN side, then down the PAN side. A dot marks where one output feeds two places.

All 63 convolutions together: 4,371,456,000 multiplications per 640×640 image. Counted as 2 operations per multiply-add, that is 8,742,912,000 ≈ 8.74 billion operations; Ultralytics publishes 8.7 GFLOPs for YOLOv8n at 640×640, which matches.

YOLOv8 sizes

YOLOv8 comes in five sizes, n (nano), s, m, l and x, built from one definition file (yolov8.yaml). All five have the structure shown in the diagram, with the same feature-map sizes. They differ only in the number of channels (width) and the number of bottlenecks in each C2f block (depth). The diagram applies to all five; the operation cards and the details page give the YOLOv8n figures.

Names used in the diagram

B3, B4
Backbone outputs of Stage P3 and Stage P4, kept in memory for the neck (skip connections).
S5
Output of SPPF, the end of the backbone (P5 level). Used twice by the neck.
N4
Neck intermediate at P4 level (FPN pass). Stays inside the neck; used twice.
OUT3, OUT4, OUT5
Final neck outputs, one per scale. Each goes to its own detection head.

Abbreviations

YOLO
You Only Look Once: the whole image is processed in a single pass of the network.
P2, P3, P4, P5
Pyramid level n: the feature map shrunk by 2ⁿ (P3 = 8×, P4 = 16×, P5 = 32×).
Conv
Convolution layer. In YOLOv8, "Conv" means convolution + batch normalisation + SiLU.
Stride
How far the filter moves each step. Stride 2 halves width and height.
Up / Down
Upsample ×2 (nearest neighbour) / downsample ×2 (stride-2 conv).
BN
Batch normalisation: rescales activations to keep training stable.
SiLU
Sigmoid Linear Unit: the activation function, x · sigmoid(x).
C2f
CSP bottleneck with 2 convolutions, "f" usually read as "faster": YOLOv8's main feature block.
CSP
Cross Stage Partial: split channels so only part goes through the heavy layers, then merge.
SPPF
Spatial Pyramid Pooling – Fast: chained max-pools that add context at several sizes.
FPN
Feature Pyramid Network: the top-down path in the neck (deep → shallow, by upsampling).
PAN
Path Aggregation Network: the bottom-up path in the neck (shallow → deep, by stride-2 conv).
Concat
Concatenate: stack two feature maps along the channel dimension.
DFL
Distribution Focal Loss: predicts each box-edge distance as probabilities over 16 bins.
NMS
Non-Maximum Suppression: removes overlapping duplicate boxes, keeping the best.
IoU
Intersection over Union: overlap of two boxes, from 0 (none) to 1 (identical).
COCO
Common Objects in Context: the standard dataset with 80 object classes.
