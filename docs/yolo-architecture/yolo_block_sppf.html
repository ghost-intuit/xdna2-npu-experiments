SPPF

Structure

The three max-pools are chained, each working on the previous result. Numbers on the lines are channels.

Memory held, step by step

Values held in memory while each step runs. Assumptions: a result is freed after its last use in this block; a step's output is allocated while its inputs are still held; a concatenation is done in place, each part written directly into its slot of the concatenated tensor, so it copies nothing. Tensors that later blocks also need are counted only while this block uses them. The darkest bar is the peak.
