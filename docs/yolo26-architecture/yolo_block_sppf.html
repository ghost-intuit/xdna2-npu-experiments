SPPF

Adds context at several scales with three chained 5×5 max-pools, then adds its input to the result. Its output goes to C2PSA.

Structure

The three max-pools are chained, each working on the previous result. The SPPF input is added to the result at the end. Numbers on the lines are channels.

SiLU rows count one multiplication per value in the table; they are not in the multiplication totals, which count the convolutions and the attention matrix products only.

Each max-pool output is the maximum of 25 values: 24 comparisons, no multiplications. In ultralytics 8.4.178 the first 1×1 convolution of SPPF has no activation (block.py line 229, act=False), for every model built from its yaml file. The released YOLOv8 code (ultralytics 8.3.0 and earlier) and the pretrained YOLOv8n weights use SiLU there, as the YOLOv8n pages show.
