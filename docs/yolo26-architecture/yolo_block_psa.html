C2PSA

Applies attention to half of the channels: each position of the 20×20 map is combined with every other. Its output S5 ends the backbone and is used twice by the neck.

Memory held, step by step

Values held in memory while each step runs. Assumptions: a result is freed after its last use in this block; a step's output is allocated while its inputs are still held; a concatenation is done in place, each part written directly into its slot of the concatenated tensor, so it copies nothing. Tensors that later blocks also need are counted only while this block uses them. The two attention matrices (one per attention head) are held from the qTk step until v · AT has read them. Softmax works in place. The darkest bar is the peak.
