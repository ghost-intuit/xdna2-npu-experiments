YOLO26n architecture

For two kinds of reader: those learning how YOLO26n works, and engineers implementing YOLO26n inference on hardware (NPUs, neural processing units; FPGAs, field-programmable gate arrays; and other accelerators). Inference only; training is mentioned only where it explains the structure.

How to read it: the backbone runs top to bottom and finishes first. Its outputs B3, B4 and S5 are kept and used later by the neck. The neck then runs in the numbered order 1 → 4: up the FPN side, then down the PAN side. A dot marks where one output feeds two or more places. Shapes are rows × columns × channels.

YOLO26 sizes

YOLO26 comes in five sizes, n (nano), s, m, l and x, built from one definition file (yolo26.yaml). The diagram applies to all five: the same blocks, the same connections and the same feature-map sizes (grid sizes). They differ in the number of channels (width), the number of inner units in each C3k2 block and of PSABlocks in C2PSA (depth), and in the type of inner unit in Stages P2 and P3. The operation cards, the block pages and the operations page give the YOLO26n figures.

Names used in the diagram

B3, B4
Backbone outputs of Stage P3 and Stage P4, kept in memory for the neck (skip connections).
S5
Output of C2PSA, the end of the backbone (P5 level). Used twice by the neck. In YOLOv8n, S5 is the SPPF output; in YOLO26n the SPPF output goes only to C2PSA and has no letter name.
N4
Neck intermediate at P4 level (FPN pass). Stays inside the neck; used twice.
OUT3, OUT4, OUT5
Final neck outputs, one per scale. Each goes to its own one-to-one detection head and to the one-to-many detection head of the same level.
Main path
The path drawn in solid lines: one-to-one detection heads, Decode, Top-300 selection, Output. NMS-free; selected with nms=False.
Secondary path
The path drawn in dashed lines: one-to-many detection heads, Decode + NMS, Output. In ultralytics 8.4.178 this is the default for predict, val and export.

Abbreviations

YOLO
You Only Look Once: the whole image is processed in a single pass of the network.
P2, P3, P4, P5
Pyramid level n: the feature map shrunk by 2ⁿ (P3 = 8×, P4 = 16×, P5 = 32×).
Conv
Convolution layer. In Ultralytics models, "Conv" means convolution + batch normalisation + SiLU. Some Conv layers of YOLO26 have no activation; the explanations name them.
DWConv
Depthwise convolution: each channel is filtered on its own (one 3×3 filter per channel).
Stride
How far the filter moves each step. Stride 2 halves width and height.
Up / Down
Upsample ×2 (nearest neighbour) / downsample ×2 (stride-2 convolution).
BN
Batch normalisation: rescales activations to keep training stable.
SiLU
Sigmoid Linear Unit: the activation function, x · sigmoid(x).
Sigmoid
The function 1 / (1 + e⁻ˣ); maps any value to the range 0 to 1.
CSP
Cross Stage Partial: split channels so only part goes through the heavy layers, then merge.
C2f
CSP bottleneck with 2 convolutions: YOLOv8's main feature block.
C3k2
Ultralytics block, a form of C2f whose inner units can be C3k blocks (or a bottleneck followed by a PSABlock). YOLO26's main feature block.
C3k
Ultralytics block: a C3 block (CSP bottleneck with 3 convolutions) with a selectable kernel size. Used as the inner unit of C3k2.
PSA
Position-sensitive attention (name in the Ultralytics code). YOLOv10, where the block comes from, calls it partial self-attention.
PSABlock
Attention followed by an FFN, each with a residual add.
C2PSA
CSP block with PSABlocks on half of the channels (C2f-style split, 2 convolutions).
Attention
An operation in which each position takes a weighted sum over all positions; the weights come from the products of queries and keys, normalised by softmax.
q, k, v
Query, key and value: the three tensors that an attention block computes from its input.
Attention head
One of several parallel attention computations inside one attention block (2 in each YOLO26n attention block). Not the same as a detection head.
FFN
Feed-forward network: here two 1×1 convolutions, the first with SiLU.
Softmax
Turns a row of values into positive values that sum to 1: eˣ divided by the sum of eˣ over the row.
Top-k
Selection of the k largest values (here k = 300).
SPPF
Spatial Pyramid Pooling – Fast: chained max-pools that add context at several sizes.
FPN
Feature Pyramid Network: the top-down path in the neck (deep → shallow, by upsampling).
PAN
Path Aggregation Network: the bottom-up path in the neck (shallow → deep, by stride-2 convolution).
Concat
Concatenate: stack two feature maps along the channel dimension.
One-to-one
Training assignment in which each object is matched to exactly one prediction. The detection heads learn to give one prediction per object, so no NMS is needed.
One-to-many
Training assignment in which each object is matched to several predictions, as in YOLOv8. The output contains duplicates and needs NMS.
End-to-end
The network output is the final list of detections, with no NMS after it. Ultralytics setting end2end.
reg_max
Number of bins per box-edge distance. YOLOv8: 16 (with DFL). YOLO26: 1 (one value per distance, no DFL).
DFL
Distribution Focal Loss: in YOLOv8, each box-edge distance is predicted as probabilities over 16 bins. Not used in YOLO26.
NMS
Non-Maximum Suppression: removes overlapping duplicate boxes, keeping the best.
IoU
Intersection over Union: overlap of two boxes, from 0 (none) to 1 (identical).
x1, y1, x2, y2
Box corners: left, top, right, bottom, in pixels.
COCO
Common Objects in Context: the standard dataset with 80 object classes.
FLOPs, GFLOPs
Floating-point operations; GFLOPs: billions of them. Counted as 2 per multiply-add.
NPU
Neural processing unit: an accelerator for neural networks.
FPGA
Field-programmable gate array: a chip whose logic is configured after manufacture.
CPU
Central processing unit.
BGR, RGB
Channel orders of a colour image: blue, green, red; red, green, blue.
int8, bf16, fp16, fp32, bfp16
Number formats: 8-bit integer; 16-bit brain floating point; 16-bit and 32-bit floating point; block floating point (on the operations and block pages).
kB, MB
Kilobyte (1,000 bytes), megabyte (1,000,000 bytes).
AEDT
Australian Eastern Daylight Time, the time zone of the edit times.
