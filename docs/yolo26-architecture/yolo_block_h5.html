SiLU rows count one multiplication per value in the table; they are not in the multiplication totals, which count the convolutions and the attention matrix products only.

400 grid positions, each with 4 box values and 80 class values. In ultralytics 8.4.178 the box and class outputs are joined in Decode. The YOLOv8n pages, written from the released YOLOv8 detection head, show a concatenation per detection head; both orders give the same values. In ultralytics 8.4.178, predict, val and export use the one-to-many detection heads with NMS by default; the one-to-one detection heads run, NMS-free, with the setting nms=False (engine/predictor.py line 476, engine/validator.py lines 167–168 and 197, engine/exporter.py lines 724–725, cfg/default.yaml line 61). In the code, the box branches of all three levels run first, then the class branches (nn/modules/head.py lines 176–177); this page shows one level.
